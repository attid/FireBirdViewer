# 019: BOOLEAN inline editor

## Контекст

Полная форма записи поддерживает BOOLEAN через select, но inline-редактор
таблицы всегда создаёт текстовый input. Причина подтверждена через Playwright:
ячейка не содержит тип колонки, поэтому клиентский код не может выбрать
подходящий контрол.

Пользователь подтвердил план и точный список файлов сообщением `++`.

- NULL остаётся доступен только в полной форме редактирования записи.
- Остальные типы продолжают использовать существующий текстовый inline input.
- BOOLEAN select сохраняет значение сразу после выбора.
